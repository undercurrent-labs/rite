# Builtin functions

The 103 bare names the language resolves without any `@capability` prefix, generated from the resolver's own list.

Treat them as reserved when naming a module export: an exported function with one of these names replaces the builtin for every file that imports the module. A local binding inside one function is fine; an export is not.
