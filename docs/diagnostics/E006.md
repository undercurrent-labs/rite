# E006

An escape sequence the string grammar does not define, most often a regex
written in an ordinary string literal.

## Failing example

```rite compile_fail
pattern ← "\d+"
```

## Corrected

```rite exec
pattern ← r"\d+"
! @console.println(pattern)
```

A raw string `r"…"` takes every character literally — backslashes and braces
included — so a pattern needs no escaping at all. See
[Text patterns](../book/regex.md).
