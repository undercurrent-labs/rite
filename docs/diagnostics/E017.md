# E017

`?` on a host call that never answers a result. `@fs.exists` answers a bool
and `@clock.sleep` answers none; both are effectful, so the `!` is right and
the `?` looks right beside it — and it used to fail only at runtime, on the
line's first execution.

## Failing example

```rite compile_fail
present ← ! @fs.exists("/tmp")?
```

## Corrected

```rite exec
present ← ! @fs.exists("/tmp")
! @console.println(str(present))
```

Which calls answer results is in the
[capability reference](../generated/capabilities.md), and
`rite describe capability fs` prints the same table.
