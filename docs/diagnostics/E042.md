# E042 Unknown capability

`@name` starts a capability path or qualified module access. When `name` is
neither a capability namespace (`@fs`, `@http`, …) nor a qualifier bound by a
`use` in this file, nothing can answer the call, and it is reported when you
compile rather than when the line runs.

## Failing example

```rite compile_fail
@coolio.square(5)
```

## Corrected

```rite
use coolio

@coolio.square(5)
```

The help names the fix: "if 'coolio' is a module, import it first: use coolio".
When the module *is* imported under an alias, only the alias qualifies —
`use coolio as cool` makes the access `@cool.square(5)`.

## Related

- A qualifier that exists but lacks the export is `E020` ("module `m` has no
  public `f`"), which lists what the module does export.
- An import that tries to bind a capability namespace (`use fs`) is `E022`;
  alias it.
